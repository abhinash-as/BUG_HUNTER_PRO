# Contributing to BUG_HUNTER_PRO

Thank you for your interest in contributing to BUG_HUNTER_PRO.

## How to Contribute

You can contribute by:

* Reporting bugs
* Suggesting new features
* Improving documentation
* Improving existing code
* Submitting pull requests

## Reporting Bugs

When reporting a bug, please provide:

* A clear description of the problem
* Steps to reproduce the issue
* Expected behavior
* Actual behavior
* Python version and operating system details

## Pull Requests

Before submitting a pull request:

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Test your changes
5. Submit a pull request with a clear description

Please keep contributions focused, clean, and well documented.

## Responsible Use

All contributions should support legal, ethical, and authorized security testing.
