# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or security issue in BUG_HUNTER_PRO, please report it responsibly.

Please avoid publicly sharing sensitive vulnerability details before they have been reviewed.

When reporting an issue, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Affected version, if applicable
* Any additional information that may help reproduce or understand the issue

Thank you for helping improve the security and reliability of BUG_HUNTER_PRO.
