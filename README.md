# 💀 BUG HUNTER PRO

> Automated Web Security Scanner & Attack Surface Analyzer

BUG HUNTER PRO is a Python-based web security scanner designed for **authorized security testing, educational purposes, and security research**.

## 🚀 Features

* 🔍 Automated Web Security Scanning
* 🛡️ Security Header Analysis
* 🔐 TLS & HTTPS Security Checks
* 💉 Injection Vulnerability Checks
* 🍪 Cookie & CORS Security Checks
* 📂 Sensitive File Exposure Detection
* 🐛 Error & Information Disclosure Checks
* 🔑 Authentication & CSRF Checks
* 🌐 DNS & Subdomain Reconnaissance
* 🔌 Common Port Exposure Checks
* 📊 Security Score & Grade
* 📄 JSON & HTML Report Generation

## ⚙️ Requirements

* Python 3.8+
* requests
* urllib3
* dnspython
* pyOpenSSL

## 📥 Installation

```bash
git clone https://github.com/abhinash-as/BUG_HUNTER_PRO.git
cd BUG_HUNTER_PRO
pip install -r requirements.txt
```

## 🚀 Usage

```bash
python3 bug_hunter_pro.py
```

Enter the target URL when prompted and the scanner will start the security analysis.

## 📄 Reports

BUG HUNTER PRO generates:

* JSON Report
* HTML Report
* Security Score
* Security Grade
* Vulnerability Findings

## ⚠️ Disclaimer

BUG HUNTER PRO is intended for **educational purposes and authorized security testing only**.

Only test websites and systems that you own or have explicit permission to test.
